✨ 平台功能簡介

私人 NAS 與 WebDAV 跨裝置線上閱讀器 · 免下載整檔、即時串流
📚

全格式即時串流

支援 EPUB、TXT、PDF、MOBI / AZW3 小說與 CBZ 漫畫；依章節按需串流載入，自動偵測 UTF-8 / GBK / Big5 編碼，也可直接上傳本地檔案閱讀。

📐

PDF 智慧重排三模式

內建文字擷取與排版修復引擎，自動合併跨行斷句、移除重複頁眉與頁碼，支援「智慧重排」、「原始斷行」與「原版 PDF」檢視隨時切換。

🖼️

CBZ 漫畫閱讀模式

支援自然數序頁碼排列與 ComicInfo.xml 自動分話，提供「條漫連續捲動」、「單頁翻頁」與「雙頁對開」，並可切換日漫（右→左）或美韓漫（左→右）翻頁方向。

⚡

BOOX / EinkBro 與翻頁器調教

專為 BOOX Note Air6 C + EinkBro 調校無動畫零殘影切換、墨水高對比主題、簡繁轉換與直橫排；支援方向鍵／空白鍵與藍牙翻頁器自訂學習配對。

🖍️

螢光筆與電磁筆手寫筆記

選字即可標記彩墨螢光筆與文字批註；開啟「畫線/手寫」支援 BOOX 電磁筆手寫、筆尾橡皮擦與手指防誤觸（手指維持滑動不誤畫），統一收錄於「筆記」分頁。

☁️

跨裝置同步與邏輯搜尋

設定同步識別碼即可跨電子閱讀器、手機與電腦同步進度、書籤與筆記（相容 NAS 與 WebDAV）；搜尋支援 空白/&(且)、|(或)、-(排除) 與括號跨繁簡比對。

⚙️ NAS 連線與跨裝置同步設定

在您的手機、平板與電腦輸入相同的識別碼（例如 1234 或您的專屬名稱），即可自動同步所有書籍的閱讀章節、捲動百分比、書籤與字體主題設定。
若您直接透過 NAS Docker 網址開啟本網頁，請保持留空；若您從 GitHub Pages 開啟，可填入您的 NAS 伺服器網址。
除了直接讀取 Docker 掛載的 /novels 本機資料夾外，亦可同時透過 WebDAV 協定遠端讀取 NAS 上的小說。

📤 新增書籍 / 漫畫至書庫 (.epub / .txt / .pdf / .mobi / .cbz)

若已連線 NAS 伺服器，檔案將直接存入 NAS 的 /novels 對應子資料夾中；若為純前端預覽模式，則會載入至瀏覽器記憶體中立即閱讀。

🏷️ 設定書籍分類狀態

💡 選擇「依進度自動」時，未開始將顯示「未讀」、閱讀中為「正在讀」、讀到末章最後自動標為「已讀完」；所有分類皆會跨裝置雲端同步。

⬇ 下載到本機（離線省電閱讀）

🔋 省電建議：外出或長時閱讀可先點「下載原始檔案」存到閱讀器本機，或存進「離線書庫」後關閉 Wi-Fi 與 Tailscale，完全不耗聯網電量。
